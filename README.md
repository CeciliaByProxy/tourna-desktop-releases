# tourna.gg desktop releases

Installers and update files for the tourna.gg desktop app. This repository holds
releases only; it contains no source code.

Download the latest version from the [Releases](https://github.com/CeciliaByProxy/tourna-desktop-releases/releases/latest)
page, or from [www.tourna.gg/download](https://www.tourna.gg/download).

The app checks this repository for updates while it is online and offers to
restart when a new version has downloaded.

Builds are currently unsigned. On Windows the first launch shows "Windows
protected your PC"; choose "More info", then "Run anyway".
